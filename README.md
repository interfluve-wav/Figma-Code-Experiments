# Figma Code Experiments

A personal repository for saving and tracking Figma AI experiments.

## About

This repository serves as a collection of experiments exploring Figma's AI-powered features and code generation capabilities. Each experiment is stored here for reference, iteration, and sharing.

## Structure

Experiments will be organized as they grow. Each experiment may include:

- Figma design files or exports
- Generated code snippets
- Notes and observations

## Getting Started

Browse the repository to explore individual experiments. New experiments will be added over time as Figma AI features are explored and tested.
